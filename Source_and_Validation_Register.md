## Claim classes and acceptance rules

| Class | Acceptance rule |
|---|---|
| Exact source fact | Correct source, date, denominator and scope; no broader inference concealed as fact |
| Owner-reported experience | Attribute internally; remove identifying third-party details; owner attestation before first-person publication |
| Editorial observation | No diagnostic certainty or universal guarantee; use proportionate language |
| Suggested practice or script | Label as an option/example; never claim the founder used it or that it is clinically proven without evidence |
| Growth hypothesis | Make the intended signal measurable; do not call it validated before live results |
| Missing information | Blank or explicitly unknown; never manufacture zero, a creation date, a biography, a baseline or a result |
